# Data Visualization — Dataset Pasien

## 1. Deskripsi Proyek
Proyek ini merupakan implementasi Data Visualization menggunakan Python dan Google Colab untuk mengeksplorasi dan menganalisis dataset pasien.

## 2. Tujuan
- Memahami karakteristik dataset pasien.
- Menganalisis distribusi umur pasien.
- Membandingkan jumlah pasien berdasarkan diagnosis.
- Mengetahui proporsi status rawat pasien.
- Mengidentifikasi pola dan hubungan antarvariabel yang tersedia.

## 3. Tools dan Library
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- OpenPyXL

## 4. Metode Analisis
1. Membaca dataset Excel.
2. Memeriksa struktur dan kualitas data.
3. Melakukan penanganan data yang diperlukan.
4. Membuat visualisasi data.
5. Menginterpretasikan hasil visualisasi.
6. Menyusun kesimpulan berdasarkan hasil analisis.

## 5. Jenis Visualisasi
1. Histogram: distribusi umur pasien.
2. Bar Chart: jumlah pasien berdasarkan diagnosis.
3. Pie Chart: persentase status rawat.
4. Boxplot: distribusi umur berdasarkan status rawat.
5. Stacked Bar Chart: diagnosis berdasarkan status rawat.
6. Heatmap: frekuensi diagnosis dan status rawat.

## 6. Hasil dan Insight
Bagian ini diisi berdasarkan hasil aktual dari grafik yang dihasilkan di Google Colab.

## 7. Kesimpulan
Kesimpulan dibuat berdasarkan pola distribusi umur, kategori diagnosis, status rawat, dan temuan lain yang terlihat pada visualisasi.

## 8. Cara Menjalankan
1. Buka file visualisasi_pasien.ipynb.
2. Buka notebook menggunakan Google Colab.
3. Siapkan dataset yang telah dianonimkan dan diizinkan untuk dibagikan.
4. Jalankan setiap sel kode secara berurutan.

## 9. Privasi Data
Data identitas pasien tidak disertakan dalam publikasi proyek. Dataset untuk demonstrasi publik harus dianonimkan dan tidak mengungkap informasi pribadi pasien.
